# 🕳️ Internet Rabbit Hole Stopper

### 🚧 Work in Progress
This app is currently in active development. Features are being added and refined frequently.

---

> **Detect the Spiral.**

**Internet Rabbit Hole Stopper** is an browser extension that monitors your browsing patterns to detect when you're falling down a "rabbit hole" of unproductive content. It uses semantic analysis to recognize deep-dives and provides a gentle pull-back to keep you on track.

---

## 🔬 How it Works

Using a **Hybrid Velocity-Keyword Algorithm**, the extension tracks:
- **Topic Density**: How many related pages you've visited in a short window.
- **Velocity**: How fast you're clicking through links on a single topic.
- **Semantic Drift**: Recognizing when you've moved from "Research" into "Mindless Exploration."

---

## ✨ Features

- **🧠 Real-time Reasoning**: The UI explains *why* it thinks you're in a rabbit hole.
- **🚀 Dynamic Sensitivity**: Adjust how strict the "Stopper" is based on your current focus mode.
- **📊 Spiral Feedback**: Visual feedback when the algorithm detects a high-velocity topic spiral.
- **🧩 Manifest V3**: Optimized for performance and low memory footprint.
- **🌐 Cross-Tab Tracking**: Monitors your behavior across your entire browser, not just a single tab.

## 🛠️ Installation

1. Download/Clone this repo.
2. Go to `chrome://extensions/`.
3. Enable **Developer Mode**.
4. Click **Load unpacked** and select this directory.
